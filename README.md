# 🎟️ Event Ticketing Platform

## 📌 Project Overview
An online platform for booking and managing event tickets.  
The system allows users to browse events, purchase tickets, and receive confirmations digitally.

---

## 👨‍💻 Team Members & Responsibilities
The project is divided into **4 equal modules**, each assigned to one member:

### Member 1 – Frontend UI & User Module (Sarouth Zakky)
- Design website layout (HTML, CSS, React components).  
- Implement user registration & login forms.  
- Integrate authentication with backend API.  
- Ensure responsive design (desktop + mobile).  

### Member 2 – Event Management Module (Fathima Raihana)
- **Backend:** Build APIs in Django for creating, updating, deleting events.  
- **Database:** Design event-related tables (event name, date, location, tickets available).  
- **Frontend:** Create event listing & detail pages in React.  
- Add search & filter functionality for events.  

### Member 3 – Ticketing & Payment Module (Mohamed Sharaf)
- **Backend:** Implement ticket booking logic.  
- Generate unique ticket IDs (store in database).  
- Integrate Stripe/PayPal for online payments.  
- **Frontend:** Ticket booking page + payment confirmation page.  

### Member 4 – Admin & Deployment Module (Zainab)
- **Backend:** Create admin dashboard for organizers (track ticket sales, manage events).  
- Implement email notifications (ticket confirmation, reminders).  
- Deploy backend (Heroku/PythonAnywhere) + frontend (Vercel/Netlify).  
- Set up PostgreSQL in production.  

---

## 🛠️ Technology Stack
- **Frontend:** HTML, CSS, JavaScript (React.js recommended for SPA)  
- **Backend:** Python (Django Framework)  
- **Database:** PostgreSQL (SQLite for development/testing)  
- **Version Control:** Git & GitHub  
- **Others (recommended):**
  - Tailwind CSS / Bootstrap for UI  
  - REST API for communication  
  - Stripe / PayPal for payments  
  - Docker (optional, for deployment)

## 🚀 Features (Planned)
